### 🌟 Why This Bot?

Students daily ask same doubts:
- Course fees ethra?
- Placement kittumo?
- CTF Labs undo?
- Live Hacking classes undo?

This RAG bot retrieves answers from OUR PDFs & website content.

### 🚀 Features

- ✅ 100% Practical Training Info
- ✅ CTF & Real-World Hacking Labs
- ✅ Placement Assured FAQ
- ✅ Affordable Fees & Batch Details
- ✅ Ethical Hacking | Cybersecurity | Linux | Networking
